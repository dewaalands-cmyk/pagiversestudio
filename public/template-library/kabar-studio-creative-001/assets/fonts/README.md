# Font KABAR STUDIO

Empat font pengganti berikut dipakai sesuai izin pengguna. Seluruh berkas WOFF2 di-host lokal melalui @font-face; halaman tidak memerlukan unduhan font dari CDN saat dibuka.

| Font rujukan    | Font terpasang     | Weight | Berkas                       |
| --------------- | ------------------ | ------ | ---------------------------- |
| Canopee         | Bodoni Moda        | 800    | bodoni-moda-800.woff2        |
| Editorial New   | Newsreader         | 300    | newsreader-300.woff2         |
| Domaine Display | Playfair Display   | 500    | playfair-display-500.woff2   |
| Germgoth        | UnifrakturMaguntia | 400    | unifrakturmaguntia-400.woff2 |

Semua font menggunakan SIL Open Font License 1.1. Copyright dan lisensi disertakan tanpa diubah dalam berkas berikut:

- bodonimoda-OFL.txt — [sumber resmi Google Fonts](https://github.com/google/fonts/blob/main/ofl/bodonimoda/OFL.txt)
- newsreader-OFL.txt — [sumber resmi Google Fonts](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt)
- playfairdisplay-OFL.txt — [sumber resmi Google Fonts](https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt)
- unifrakturmaguntia-OFL.txt — [sumber resmi Google Fonts](https://github.com/google/fonts/blob/main/ofl/unifrakturmaguntia/OFL.txt)

Pertahankan berkas copyright dan OFL saat mendistribusikan aset. Nama keluarga font tetap nama aslinya. Nama file lokal menyebut weight yang dipakai oleh template.

Metadata URL unduhan resmi fonts.gstatic.com, ukuran berkas, serta sumber lisensi tersimpan dalam sources.json. Keluarga font dan bobotnya tidak menjadi variabel pelanggan. Skala tipografi halaman memakai basis 31px dengan rasio Minor Third 1.2.

Status: pemeriksaan aset dan pemuatan empat font di browser PASS, 0 missing. Bukti QA dan proses publikasi dicatat dalam README template.
